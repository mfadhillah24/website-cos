# Hero Header Images

Letakkan file gambar (jpg, jpeg, png, webp) di folder ini.
Gambar-gambar ini akan otomatis digunakan sebagai background slideshow pada hero section halaman beranda.

Format yang didukung: JPG, JPEG, PNG, WEBP

Tips:
- Gunakan foto landscape/horizontal untuk tampilan terbaik
- Resolusi disarankan minimal 1280x720 (HD)
